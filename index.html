Red Review: verify a delivery

Reference for checking a Red Review evidence bundle. The source and the history of every release are in github.com/kirikov/red-review-verify.

git clone https://github.com/kirikov/red-review-verify && cd red-review-verify
cargo install dcap-qvl-cli
unzip evidence.zip -d bundle
python3 verify-bundle.py bundle --reference hashes.json

Machine-readable reference: hashes.json. The verifier inside each bundle loads it from this page by default.
